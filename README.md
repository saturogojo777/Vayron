# Vayron — Modern DTC Streetwear Storefront

A high-performance, lightweight React & Tailwind CSS web application built for **Vayron**. Features clean SEO routing, accessible focus-trapping modals, WebP/AVIF image support, and a seamless direct WhatsApp checkout flow.

## 🚀 Tech Stack

- **Frontend:** React 19, Vite, Tailwind CSS v4
- **Routing:** Browser History API (Clean SEO URLs)
- **Accessibility:** Focus-trapped modals & custom hooks
- **Optimization:** WebP / AVIF multi-format fallback support
- **Checkout:** Instant WhatsApp Order Integration
